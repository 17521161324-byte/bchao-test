# 提取规则梳理与转化 - 功能规格

## 背景与目标

B 超语音测试平台已经具备 ASR 转写、ASR 文本转化评估、规则配置版本、文本验证和结构化结果对比能力。当前任务聚焦把"提取规则"梳理成可配置、可预览、可验证的业务规则库，覆盖辅助生殖 B 超语音里的医学名词、定位词、文本切换、数据提取和警示校验。

目标不是重做一套新系统，而是在现有 `conversion_config`、`conversion_engine`、`text_validation` 和 `conversion_eval` 链路上形成可实施的最小方案：

- 词库管理：医学名词 + 定位词按单条管理，并支持多个近似词/ASR 错词。
- 文本切换规则：根据左右卵巢、左右侧、换边词和上下文切割业务片段。
- 数据提取规则：从业务片段中提取内膜、卵巢大小、卵泡明细等结构化字段。
- 警示规则：对医疗数据异常、侧别不明确、缺失定位词等情况提示人工复核，不自动猜测。

## 用户场景

1. 词库管理员维护"右卵巢/左卵巢/内膜/换边"等标准词，并给每个标准词配置多个近似词、错词、必要上下文、排除上下文和风险等级。
2. 评估人员粘贴一段 ASR 文本，选择规则版本后预览转化结果，查看命中的词库、业务片段、结构化字段和警示项。
3. 评估人员在文本验证页面选择 ASR 结果，使用 LLM 纠错文本或人工覆盖文本，再用规则库提取字段并与真实 B 超结果对比。
4. 当语音缺失单个定位词时，例如先报"左卵巢大小"，后续只报"卵泡 15.2、14.8"，系统按最近明确侧别归属；当出现"换边/右边/左边"等切换词时切换当前侧别。
5. 当卵泡尺寸大于 40mm、卵巢单边尺寸小于 10mm、左右侧缺失或冲突时，系统生成警示，进入人工复核，不静默修改结果。

## 本次需求范围

- 梳理并固化规则库分类和字段口径，形成实施方案。
- 复用现有配置模型：`ConversionConfigVersion`、`ConversionLexiconEntry`、`ConversionRuleEntry`。
- 复用现有入口：`/api/conversion-config/*` 版本/词库/规则/预览接口，`run_conversion()` 转化链路，`/api/text-validation/runs` 验证链路。
- 明确后续开发需要补齐的配置字段、接口返回、前端展示、迁移和测试范围。
- 明确提取规则中的安全边界：数字不可猜、左右侧不可猜、医疗决策不可猜。

## 不在本次范围

- 本阶段不进行正式业务开发，只产出规划文档。
- 不重新初始化项目，不替换 FastAPI/Vue/SQLite 技术栈。
- 不引入 Alembic 等正式迁移框架。
- 不新增 ASR/LLM provider，不调整模型配置协议。
- 不做 ASR 训练、LLM 微调或自动生成生产词库。
- 不实现复杂 NLP/向量召回/医学知识图谱。
- 不自动修正无法从原文追溯的真实数字、左右归属或医疗决策。

## 业务流程

1. 初始化或选择规则版本。
2. 维护词库条目：标准医学名词、定位词、近似词/错词、上下文、动作、风险等级。
3. 维护规则条目：文本切换、字段提取、范围校验、警示规则，系统规则默认不可编辑，参数化规则可编辑。
4. 在配置页使用"版本测试"预览 ASR 文本转化。
5. 转化引擎按顺序执行：基础清洗 → 数字标准化 → 医学术语纠错 → 业务片段定位/转化 → 字段解析 → 风险拦截。
6. 文本验证页选择检查记录和 ASR 结果，执行 LLM 完整纠错或人工覆盖文本，再运行规则提取。
7. 系统把提取字段与 `BUltraResult` ground truth 对比，输出准确率、字段差异和警示项。
8. 评估人员根据预览和验证结果调整草稿规则版本，验证通过后发布；已发布版本不可直接修改。

## 关键业务规则

以下规则为已确认口径，实现必须遵循：

- **卵泡尺寸 > 40mm**：照常提取该卵泡数据，同时在警示项中标记超范围，由人工复核决定取舍；不阻断提取，不静默丢弃。
- **卵巢大小单边 < 10mm**：长或宽**任一维**小于 10mm 即触发警示，进入人工复核。
- **医疗名称（如左右卵巢、内膜）识别错误、换边词错误**：影响较小，**不生成警示**，由词库纠错（近似词/错词映射为标准词）处理。
- **警示仅由数据异常触发**：当数字等医疗数据满足异常校验规则时生成警示（如卵泡尺寸 > 40mm、卵巢单边任一维 < 10mm、左右侧缺失或冲突、数字边界不确定等），提示人工复核；不因医疗名词/换边词类错误产生警示。
- **缺失定位词时的侧别归属**：按最近明确侧别继承；出现"换边/右边/左边"等换边词时切换当前侧别（继承窗口的文本边界见"待确认事项"）。

## 页面与交互要求

### 规则配置页（ConversionConfig）

- **版本管理（列表展示）**：页面顶部以**版本列表表格**直观展示所有版本（状态/版本名称/编码/词库数/规则数/更新时间），点击行切换当前操作版本，当前版本行高亮；支持新建草稿、克隆、发布、回滚。**删除**：**草稿/测试中、已回滚版本可删除**（删除时级联删除其词库与规则，二次确认提示"删除后历史规则不可恢复"）；**已发布（当前生效）版本不可删除**。
- **Tab 1 词库管理**：按"标准词 + 多近似词"分组展示（组头显示标准词与近似词数量），支持增删改、CSV 导出；已发布版本只读。**新增/编辑弹窗按标准词批量维护**：填写标准词与业务场景后，可在同一弹窗内添加多个近似词（每条含错误词/动作/风险/启用开关），编辑时整组加载近似词列表。**表格列与弹窗配置保持一致**：仅展示 错误词/标准词/场景/动作/风险/状态/操作 七列（编码、上下文、置信度等列不在界面展示，DB 数据保留仍参与引擎匹配）。
- **Tab 2 规则管理（二级 tab）**：内部分为五个二级 tab——**文本切换规则**（左右定位词、换边词、侧别继承）、**数据提取规则**（字段提取与范围校验）、**警示规则**（数字异常校验，如卵泡 > 40mm、卵巢单边 < 10mm）、**引擎基础步骤**（基础清洗/数字标准化/医学术语纠错）、**参数化规则**（可编辑）；系统内置规则只读展示，参数化规则可编辑；已发布版本只读，修改需克隆草稿。
- **Tab 3 版本测试**：粘贴 ASR 原文 → 预览转化结果，展示转化后文本、命中词库/规则、业务片段（定位词/医学名词/数据/噪声）、字段解析结果、警示项与三态风险标签（风险阻断 / 风险通过 / 有警示待复核）。

### 文本验证页（TextValidation）

- 选择检查记录与 ASR 结果、规则版本 → LLM 完整纠错或人工覆盖文本 → 规则提取 → 与真实 B 超结果（ground truth）对比，展示准确率、字段差异、命中规则、业务片段、警示项；验证记录可历史查询。

## 验收标准

1. 文档明确规则库分为词库、文本切换、数据提取、警示校验四类，并能映射到现有代码入口。
2. 需求范围与技术设计、任务清单保持一致，不包含无关重构或技术栈替换。
3. 词库管理方案支持"标准词 + 多个近似词/错词"的表达方式，且不破坏现有 `ConversionLexiconEntry` 单条错词模型。
4. 文本切换规则明确左/右显式定位词、换边词、缺失定位词时的继承策略和复核边界。
5. 数据提取规则明确卵泡、卵巢大小、内膜字段的范围和格式校验。
6. 警示规则明确超范围、侧别冲突、数字边界不确定、否定词/决策词的处理策略；警示仅由数据异常触发（卵泡 > 40mm 提取并标记异常、卵巢单边任一维 < 10mm 等），医疗名词/换边词识别错误不生成警示。
7. 没有阻塞开发的关键待确认项；无法确认的口径已列为待确认。

## 待确认事项

- 近似词是否需要在前端以一条标准词下多行展示，后端仍保存为多条 `ConversionLexiconEntry`；建议采用该兼容方案。
- 缺失定位词时侧别继承窗口的最大文本长度/强边界（句号、换行、竖线、下一医学名词）需用真实样本回归确定。
